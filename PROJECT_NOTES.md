# PFD200 Project preparation notes

## Confirmed project concept
Personal Expense Tracker: a small local application for recording everyday spending. The motivation is to understand how repeated £20–£50 expenses accumulate. Intended career direction: Junior Software Developer.

## What to demonstrate
1. Start the application locally and add an expense.
2. Show that the history and total update.
3. Refresh and confirm SQLite persistence.
4. Reject a negative or invalid amount.
5. Delete an entry and check the new total.

## Evidence to collect yourself
- Screenshots of working application and tests
- Actual dates of development and any errors/fixes
- Your own project management board and decisions
- Your own reflective notes on what you learned
- CV, LinkedIn URL, GitHub public repository URL
- Security threat assessment and user awareness materials

## Important scope
This is a local learning demo, not a hosted financial service. There is no user login or CSRF protection. Do not deploy it publicly as-is. A public GitHub repository may host the source code without publishing a running server.
